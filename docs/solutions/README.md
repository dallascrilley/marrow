# Solutions

Repo-specific learnings from solved bugs and non-obvious fixes. Search here before
debugging recurring issues (`grep -ril "<terms>" docs/solutions/`).

Capture new learnings with the `ce-compound` skill → `docs/solutions/<category>/`.
Refresh stale docs with `ce-compound-refresh`. Categories follow ce-compound tracks
(e.g. `tooling`, `test-failures`, `runtime-errors`, `best-practices`).
