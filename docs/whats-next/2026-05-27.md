**Project goal / north star:** `agent-session-distillery` is a standalone CLI that ingests local agent transcripts from Cursor, Claude Code, Codex CLI, Kimi, and Pi, runs them through parse → reduce → summarize → extract → review → retention, and exports durable project memory including v2 atomic instincts rendered to `~/vault/wiki/projects/<project-id>/MEMORY.md`. Per `README.md`, `LAUNCH_CRITERIA.md`, and `docs/launch-proof-index.md`, v1 local ingestion, v2 instinct/vault pipeline, and P1 session-index quality gates are all launch-validated. Commit `26bd490` closed the last major quality gap (resummarize, topic detection, Kimi adapter, per-session error isolation). Work has shifted from feature delivery to post-ship validation, tracker hygiene, and extending launch contracts to the new adapter.

**Product Ideation & User Empathy:**
- **Target Persona:** Solo operator running multiple local agent harnesses (Cursor, Claude Code, Codex, Kimi, Pi); comfortable with Node CLI, env vars, cron/launchd, and optional `OPENROUTER_API_KEY`. Primary motivation: turn ephemeral agent sessions into searchable, vault-integrated memory without manual curation.
- **Core Value Path:** Discover transcripts → `ingest sync` per adapter → summarize + extract learnings → (optional) LLM review → apply to reviewed sidecar → sync instincts → `memory export-wiki` + `push-wiki` → `export-index` for Tether Session Search → (new) `quality resummarize` to upgrade stale topics on existing corpus.
- **Unmapped Friction Point:** After a big feature drop (`26bd490`), the operator has no turnkey "upgrade my existing 140-session corpus and verify topic quality improved" runbook — unit tests prove correctness but the live runtime proof artifact and scheduled-recipe docs still list only four adapters (no Kimi).
- **Feature Leap-Frog Concept:** **Session quality dashboard** — extend `quality audit` with a `--topic-distribution` mode that ranks projects by low-signal topic rate, wrapper leaks, and LLM rescue coverage, then emits a one-command remediation plan (`corpus:resummarize:dry-run` → `corpus:resummarize`). Turns passive audit into an operator-facing quality loop without requiring manual JSONL inspection.
