# What's Next — 2026-06-15

**Strategic track:** `enhance`

**Project goal / north star:** `agent-session-distillery` ingests local agent transcripts from five harnesses, distills them into searchable session indexes and vault-integrated project memory (v2 atomic instincts → `MEMORY.md`), and now ships operator automation: SessionEnd hook, scheduled pipeline with `pipeline gate`, skill evidence/report, and topic-quality audit. Per `LAUNCH_CRITERIA.md` and `docs/launch-proof-index.md`, v1/v2 P0, P1 session-index, and P2 automation gates are validated. **235 tests** pass on `main` @ `19fa870` (2026-06-14). The 2026-06-14 sprint (PR #29–#33) closed all five roadmap items including daemon-LLM separation (ADR-0007) and v2 epic closure.

## Product Strategy

- **Target Persona:** Solo operator running multiple local agent harnesses; comfortable with Node CLI, cron/launchd, optional `OPENROUTER_API_KEY`, and `~/vault`.
- **Job To Be Done:** Turn ephemeral agent sessions into durable, searchable, vault-integrated memory without manual curation — and without runaway LLM spend on idle cron ticks.
- **Core Value Path:** Transcript on disk → `ingest sync` → summarize + extract → `pipeline gate` → (optional) LLM review → `memory push-wiki` → `export-index`.
- **Activation Moment:** Scheduled pipeline completes with exit 0, vault `MEMORY.md` updates, session index grows — and OpenRouter is skipped when there is nothing new to review.
- **Current Friction:** `pipeline gate` scans all five adapters on every run; operator smoke took **60s+** on live runtime with thousands of discovered transcripts (`cursor` pending_count 3141 @ 2026-06-14). Launch contract lacked a `pipeline-gate` P2 entry until this cycle.
- **Feature Opportunity:** **Fast gate mode** — `--source` defaults for cron, optional ledger-only pending counts, or cached discover snapshot so 6-hour schedules stay under 10s when idle.
