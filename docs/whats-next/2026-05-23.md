**Launch verdict:** v1 + v2 launch-ready — all eleven P0 gates in `LAUNCH_CRITERIA.md` are `status: validated` (v1 six gates through 2026-05-18; v2 five gates through 2026-05-22). No unvalidated P0 blockers remain. Work has shifted from launch proof to corpus quality and operator tooling.

**Top user-critical gap:** Real `--llm-topic` backfill exposed weak session topics (139/140 deterministic, wrapper leaks like `brainstorming`) and no way to upgrade existing sessions — immutable manifests block re-ingest ([issue #16](https://github.com/dallascrilley/agent-session-distillery/issues/16)). Downstream Tether Session Search reads `asd.session_index.v1` and inherits bad titles.

**Project goal / north star:** `agent-session-distillery` is a standalone CLI that ingests local agent transcripts from Cursor, Claude Code, Codex CLI, and Pi, runs them through parse → reduce → summarize → extract → review → retention, and exports durable project memory including v2 atomic instincts rendered to `~/vault/wiki/projects/<project-id>/MEMORY.md`. Per `README.md` and `LAUNCH_CRITERIA.md`, v1 local ingestion and v2 instinct/vault pipeline are both launch-validated. The operator extracts value by running `ingest sync`, optional LLM review passes, and `memory push-wiki` on a cadence (`docs/recipes/scheduled-memory-pipeline.md`).

**Product Ideation & User Empathy:**
- **Target Persona:** Solo operator or small team running multiple agent harnesses locally; technical baseline is comfortable with Node CLI, env vars, and optional `OPENROUTER_API_KEY`. Primary motivation: turn ephemeral agent sessions into searchable, vault-integrated memory without manual copy-paste.
- **Core Value Path:** Discover transcripts → ingest/sync → summarize + extract learnings → (optional) LLM review → apply to reviewed sidecar → sync instincts → export/push wiki + MEMORY.md → query via session index or vault.
- **Unmapped Friction Point:** Once a session is summarized, topic/summary quality is frozen — operators cannot retroactively fix bad titles after shipping `--llm-topic` and `export-index`, yet downstream search (Tether Session Search Raycast extension) depends entirely on index topic quality.
- **Feature Leap-Frog Concept:** **`asd resummarize`** — a retention-safe reprocess command that regenerates `topic`, `topic_source`, and summary fields for selected sessions (by id, project, or `--low-signal-only`) without violating manifest/tombstone invariants, then atomically refreshes `asd.session_index.v1`. Closes the corpus-upgrade loop and multiplies value of PRs #13–#15 for all historical sessions.
