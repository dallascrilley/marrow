# What's Next — 2026-06-14

**Strategic track:** `enhance`

**Project goal / north star:** `agent-session-distillery` ingests local agent transcripts from five harnesses, distills them into searchable session indexes and vault-integrated project memory (v2 atomic instincts → `MEMORY.md`), and now ships operator automation (SessionEnd ingest hook, scheduled pipeline recipe, skill evidence/report). Recent work (PR #22–#28) shifted from launch blockers to compounding operator value: bootstrap/CI, hooks, skill adherence, checklist noise fix.

## Product Strategy

- **Target Persona:** Solo operator running multiple local agent harnesses; comfortable with Node CLI, cron/launchd, optional `OPENROUTER_API_KEY`, and `~/vault`.
- **Job To Be Done:** Turn ephemeral agent sessions into durable, searchable, vault-integrated memory without manual curation after each session.
- **Core Value Path:** Transcript on disk → `ingest sync` → summarize + extract → (optional) LLM review → `memory push-wiki` → `export-index` for Tether Session Search.
- **Activation Moment:** Operator sees a new session appear in the index with a high-signal topic and corresponding `MEMORY.md` instinct update without manual ingest commands.
- **Current Friction:** Automation pieces exist separately (SessionEnd hook, scheduled recipe, skill report) but there is no single **unattended loop proof** tying hook → ingest → audit → vault → index. Quality remediation still requires manual JSONL inspection or ad-hoc scripts.
- **Feature Opportunity:** **Session quality dashboard** — `quality audit --topic-distribution` ranking low-signal rate, wrapper leaks, and LLM rescue coverage with a one-command remediation plan.
