# Documentation

| Path | Purpose |
|------|---------|
| `decisions/` | Architecture Decision Records (ADRs). One file per decision, numbered; see `decisions/README.md`. |
| `specs/` | Concrete schema and contract specs referenced by the ADRs. |
| `recipes/` | Task-oriented how-tos for running and operating the pipeline. |

## Conventions

- New architectural decision: copy `decisions/0000-template.md` to the next number.
- Keep docs close to the code they describe; link from the top-level `README.md` when user-facing.
